# Контекст проекта

## Текущая задача

Многостраничный сайт автошколы «Драйв» по присланному ТЗ и брендбуку. Сайт должен работать как коммерческий продукт: главная, программы, тарифы, инструкторы, автопарк, филиалы, отзывы без вымышленных данных, контакты, FAQ, юридические страницы и раздел «Сведения об образовательной организации».

## Приоритеты

- Бренд: «Драйв», подпись «Автошкола». Везде использовать русское написание.
- Палитра: красный `#9E1212`, почти чёрный `#0C0C0C`, тёплый светлый фон `#F8F4F3`, белые поверхности.
- Логотип использовать только из предоставленного брендбука. Не перерисовывать знак генеративно и не менять пропорции.
- Не придумывать реальные цены, статистику, имена, отзывы, адреса, автомобили, филиалы, лицензию и реквизиты.
- Неизвестные данные оставлять плейсхолдерами до подтверждения.

## Техническое решение

- Стек текущей реализации: React + Vite + TypeScript.
- Маршрутизация: лёгкая SPA-навигация без внешнего роутера.
- Данные сайта: `src/data/site.ts`, `src/data/drive.ts`, `src/data/organization.ts`.
- Документы: `public/documents`.
- Логотипы: `public/logos`, извлечены из присланного брендбука. TODO: заменить на официальный SVG, когда он будет предоставлен.

## Публикация

GitHub Pages собирается через `.github/workflows/pages.yml`. Для Pages сохранены `base: './'` в `vite.config.mjs` и `public/.nojekyll`.

Правильный репозиторий для публикации: `https://github.com/alyayumm/drive.git`.
