# Контекст проекта

## Текущая задача

Сайт автошколы «Цитрариум»: коммерческая главная страница с категориями обучения, тарифами и базовой информацией для записи, плюс отдельный официальный раздел сведений об образовательной организации с документами и обязательными подразделами.

## Приоритеты

- Бренд: «Цитрариум», автошкола.
- Главная страница не является страницей документов; документы доступны в отдельном разделе `/svedeniya-ob-obrazovatelnoy-organizatsii`.
- Палитра: графит `#202326`, желтый `#F6B82E`, светлый фон, белые поверхности.
- Логотип и декоративные иконки используются из предоставленного брендбука и присланных PNG.
- Не выдумывать юридические данные, адреса, телефоны, лицензии, сотрудников и реальные PDF.
- Неизвестные данные не выдумывать; в публичном интерфейсе использовать нейтральные официальные формулировки.

## Техническое решение

- Стек: React + Vite + TypeScript.
- Маршрутизация: легкая SPA-навигация без внешнего роутера.
- Данные: `src/data/site.ts` и `src/data/organization.ts`.
- Документы: `public/documents`.
- Брендовые ассеты: `public/logos` и `public/brand-assets`.

## Публикация

GitHub Pages собирается через `.github/workflows/pages.yml`. Для Pages сохранены `base: './'` и `public/.nojekyll`.
