# Автошкола «Цитрариум»

React + Vite + TypeScript сайт автошколы «Цитрариум»: главная страница с категориями, тарифами и процессом обучения, а также отдельный официальный раздел сведений об образовательной организации и документов.

## Запуск

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm run lint
npm run build
npm run preview
```

## Где менять данные

- контакты, меню, SEO: `src/data/site.ts`;
- сведения об образовательной организации и документы: `src/data/organization.ts`;
- страницы и структура главной: `src/pages/HomePage.tsx`;
- логотипы из брендбука: `public/logos`;
- брендовые PNG-иконки: `public/brand-assets`;
- PDF-документы: `public/documents`.

## Ограничения

- Неподтвержденные реквизиты, адреса, телефоны, лицензии и PDF не выдумываются.
- Неизвестные данные не выдумываются и подаются нейтрально.
- Логотип и иконки используются только из предоставленного брендбука и присланных PNG.

## Публикация

Проект готов к GitHub Pages: `vite.config.mjs` использует `base: './'`, а `public/.nojekyll` остается в проекте. Workflow `.github/workflows/pages.yml` собирает `dist` и публикует сайт после push в `main`.
