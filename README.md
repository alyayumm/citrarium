# Автошкола «Драйв»

React + Vite + TypeScript сайт автошколы «Драйв» для GitHub Pages. Проект подготовлен как многостраничная SPA: главная, программы, тарифы, инструкторы, автопарк, филиалы, отзывы, контакты, FAQ, юридические страницы и раздел «Сведения об образовательной организации».

## Запуск

```bash
npm install
npm run dev
```

## Проверка и сборка

```bash
npm run lint
npm run build
```

## Где менять данные

- Общий бренд, меню, контакты и SEO: `src/data/site.ts`
- Программы, тарифы, инструкторы, автомобили, филиалы, FAQ: `src/data/drive.ts`
- Официальный раздел и документы: `src/data/organization.ts`
- Документы PDF: `public/documents`
- Логотипы: `public/logos`

## Данные, которые нельзя выдумывать

До подтверждения оставлять плейсхолдеры для цен, адресов, телефонов, филиалов, моделей автомобилей, имён инструкторов, отзывов, статистики, лицензии, реквизитов и юридических формулировок.

## CRM и аналитика

Формы сейчас работают локально и сохраняют демонстрационную заявку в браузере. Для реального подключения нужно заменить обработчик в `src/lib/crm.ts`, добавить переменные в `.env` и описать используемые сервисы в юридических страницах.

## GitHub Pages

Для публикации используется `.github/workflows/pages.yml`. В `vite.config.mjs` установлен `base: './'`, а в `public/.nojekyll` сохранён маркер для корректной раздачи статических файлов.
