# Design

## Theme

Светлый сайт автошколы «Цитрариум»: спокойная коммерческая главная с категориями, тарифами и процессом обучения, отдельный официальный раздел документов, графитовая типографика, желтый акцент, белые и светло-серые поверхности, аккуратные брендовые PNG-иконки из предоставленных материалов.

## Palette

```css
:root {
  --graphite: #202326;
  --yellow: #F6B82E;
  --surface: #FFFFFF;
  --surface-muted: #F7F7F4;
  --text-muted: #686B6E;
  --line: #E4E4DF;
}
```

## Typography

- Заголовки: Manrope ExtraBold/Bold по брендбуку.
- Основной текст и интерфейс: Manrope/Inter/system sans-serif.
- Крупные заголовки должны переноситься без переполнения на мобильных экранах.

## Layout

- Sticky header с логотипом, навигацией по главной и быстрым переходом к документам.
- Hero главной в два столбца на desktop: коммерческий текст слева, брендовый PNG-визуал справа.
- На mobile контент идет одной колонкой, без горизонтального скролла.
- Карточки используются только для реальных навигационных элементов, документов и информационных групп.

## Components

- Primary button: желтая кнопка с графитовым текстом.
- Secondary button: белая кнопка с тонкой границей.
- Иконки: PNG из `public/brand-assets` для ключевых карточек, SVG-иконки только как вспомогательные интерфейсные маркеры.
- Документы: карточки со статусом `PDF доступен`, названием, пояснением и ссылками на просмотр и скачивание.

## Asset Rules

Использовать только предоставленные пользователем брендбук, логотипы и PNG-иконки. Не добавлять случайные локальные изображения, стоки, чужие мокапы, портреты или выдуманные документы.
